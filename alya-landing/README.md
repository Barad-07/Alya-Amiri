# علياء العامري — Landing Page (Vanilla HTML / CSS / JS)

صفحة واحدة ثنائية اللغة (عربي RTL / إنجليزي LTR)، بلا أي إطار عمل وبلا مكتبات خارجية. كل الحركة مبنية بـ CSS و IntersectionObserver و requestAnimationFrame.

## التشغيل

افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا:

```bash
cd alya-landing && python3 -m http.server 8000
```

## أقسام الصفحة (بالترتيب)

| # | القسم | المعرّف | ملاحظات |
|---|---|---|---|
| 1 | Hero | `#top` | العنوان يظهر سطرًا سطرًا، والقوس ينفتح مع بارالاكس |
| 2 | المبدأ | — | الكلمات تتضح مع التمرير |
| 3 | نبذة + المؤهلات | `#about` | صورة القوس، التعريف، وشبكة من 6 مؤهلات |
| 4 | مجالات الممارسة | `#practice` | أكورديون؛ وعلى الديسكتوب صورة تتبع الماوس |
| 5 | المنهج | `#approach` | عمود ثابت (sticky) والخطوات الأربع |
| 6 | الأعمال | `#work` | تمرير أفقي مثبّت؛ يُخفى من `config.sections.work` |
| 7 | التواصل | `#contact` | بيانات التواصل ونموذج الاستشارة |
| — | الهيدر والفوتر | — | تُبنى من `js/navigation.js` |

## الملفات

```text
index.html
css/main.css          المتغيّرات + كل المكوّنات
css/animations.css    لغة الحركة
css/rtl.css           خطوط العربية وعكس الاتجاه
css/responsive.css    1024 (تابلت) و 767 (جوال) — مطابقة لـ Elementor
js/config.js          ← بيانات التواصل + إظهار/إخفاء قسم الأعمال
js/translations.js    ← كل نصوص الواجهة (en / ar)
js/data.js            ← مجالات الممارسة + الأعمال
js/i18n.js            تبديل اللغة فوري + حفظها
js/navigation.js      الهيدر، الفوتر، القائمة، التمرير للأقسام، مؤشر القسم النشط، ستارة البداية
js/animations.js      الظهور، البارالاكس، التمرير الأفقي، المؤشر، معاينة الصور
js/landing.js         رسم الأقسام المتكررة + الأكورديون + النموذج
js/main.js            ترتيب التشغيل
assets/images/        صور مؤقتة مولّدة — استبدلها
```

## ملاحظات

- **ستارة البداية** تظهر مرة واحدة في كل جلسة تصفّح.
- **وضع تقليل الحركة:** مع `prefers-reduced-motion` يظهر كل شيء ثابتًا.
- **النموذج** يتحقق من الحقول ويعرض رسالة نجاح، لكنه لا يرسل شيئًا. يُربط في ووردبريس.
- في ووردبريس ستكون لكل لغة صفحة مستقلة عبر Polylang؛ زر التبديل هنا للمعاينة فقط.

تم الفحص في Chrome على 1440 و 1024 و 390 بكسل، باللغتين: لا أخطاء JavaScript، ولا تمرير أفقي للصفحة.
